# Demonstration — texts this generator can produce

Every excerpt below was produced by running `node narrative-poc/demo.js`, which calls the
**shipped** generator (`functions/src/textGeneration.js` plus `partirEnQuete.js`'s
`buildNarrativeContext` / `narrateQuestSuccess`) over the sample catalog in
`narrative-poc/src/data/catalog.js`. Nothing here was written by hand as an output: the fragments
in the catalog were authored, the paragraphs were assembled. The random draw is seeded so this
document is reproducible; the live game draws unseeded.

The sample catalog holds **6 narrative subjects and 21 verb phrases** — 6 openings, 9 action
sentences, 6 talent flourishes. That is a realistic first-pass authoring effort, and it is worth
keeping in mind while reading: the quality below is a function of that content, not of the engine.

Duplicates are filtered out, so each scenario lists the distinct paragraphs it can produce with
this catalog. A scenario showing only two variants is showing you a content gap, honestly.
